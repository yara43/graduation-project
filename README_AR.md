# Sentinel — Chrome Popup Demo

دي إضافة بتتفتح من أيقونتها في Chrome وإنتِ على أي موقع، من غير tab جديدة.

## التشغيل
1. فكّي ضغط الملف.
2. افتحي chrome://extensions وفعّلي Developer mode.
3. اختاري Load unpacked وبعدها فولدر Sentinel_Chrome_Demo اللي جواه manifest.json.
4. من علامة البازل في Chrome اعملي Pin للإضافة.
5. افتحي أي موقع واضغطي أيقونة Sentinel. الـLogin هيظهر جوّه نافذة صغيرة فوق الصفحة.
6. اضغطي Fill demo credentials وبعدها Enter demo، وجربي اختيار ملف.

لو النسخة القديمة متثبتة بالفعل: اضغطي Reload في صفحة extensions بعد استبدال الملفات، أو احذفيها وحمّلي الفولدر الجديد.

الحساب التجريبي: demo@sentinel.local / demo123

## السلوك
- الإضافة متاحة من شريط Chrome على أي صفحة؛ لا تغيّر الصفحة ولا تقرأ محتواها.
- تظهر Hello World واختيار ملف يعرض الاسم والحجم والنوع الذي يخبرنا به المتصفح.
- الدخول تجريبي فقط، ويتم تذكّر حالة دخول الديمو محليًا حتى Sign out. لا توجد حسابات حقيقية.
- نافذة الإضافة تقفل عند الضغط خارجها؛ افتحي الأيقونة مرة أخرى لإظهارها.
- اختيار الملف مؤقت: عند إغلاق النافذة تحتاجين لاختياره مرة أخرى.
- لا يُرسل الملف لأي مكان، ولا يوجد فحص أمني أو كشف تحميل تلقائي في هذه النسخة.
- لا تحتاج npm أو server أو API key.

## الملفات
manifest.json: تعريف الإضافة.
popup.html: نافذة الإضافة والـLogin.
app.js: سلوك الدخول واختيار الملف.
styles.css: شكل الواجهة.
icons/: الأيقونات.
